# Contributing

Thanks for considering a contribution!

## Before you start
- Open an issue to discuss large changes.
- Keep the project beginner-friendly and lightweight.
- Do not add analytics, tracking, external requests, or remote data storage without discussing the privacy impact first.
- Never commit real customer records, credentials, API keys, or tokens.

## Development
The current prototype is a single static HTML file. Open `index.html` in a modern browser; no build step or third-party dependencies are required.

## Pull requests
- Explain the problem and the change.
- Include clear manual test steps.
- Test at desktop and mobile widths.
- Check keyboard navigation and form labels.
- Confirm CSV import/export works with quoted commas and quotes.
- Do not claim a test passed unless you ran it.
