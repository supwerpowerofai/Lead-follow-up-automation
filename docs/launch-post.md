# Public Launch Draft

## Title
I built a small, local-first lead follow-up tracker for service businesses — feedback welcome

## Post
I’m sharing an early open-source prototype for small service businesses that need a simple way to track enquiries and remember the next follow-up.

**What it currently does**
- Track leads, status, owner, and next follow-up date
- Filter leads due today or overdue
- Import and export CSV
- Store records locally in your browser

**What it does not do**
- No cloud sync or multi-user accounts
- No automatic WhatsApp, SMS, or email sending
- No CRM integration yet

It’s intentionally lightweight and still needs more real-browser testing. Please use fictional data while testing and don’t treat it as a production customer-data system.

Repository: https://github.com/supwerpowerofai/Lead-follow-up-automation

The most useful feedback would be:
1. Can you import the sample CSV and export it again without losing the fields you need?
2. What is confusing on the first run?
3. Which small improvement would make this useful for your daily follow-up routine?

I’ll prioritize reproducible bug reports and practical feedback over adding features just for the sake of it.
